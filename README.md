# Chocolate Sales Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to explore chocolate sales performance across geographies, product categories, salespeople, and time. The report brings key sales and shipment indicators together on a single page to support quick business reviews.

## Tools Used
- Microsoft Power BI Desktop
- Power BI data modeling and visualizations

## Dashboard Features
- **Total Sales:** High-level sales KPI.
- **Total Boxes:** Boxes sold KPI.
- **Shipment Count:** Shipment volume KPI.
- **Sales by Geography:** Compare total sales across geographic markets.
- **Sales Trend:** View total sales by year and month.
- **Sales by Product Category:** Compare sales across product categories.
- **Performance Table:** Explore salesperson, product category, total sales, total boxes, and LBS % together.
- **LBS %:** A percentage measure included in the report (check its model definition before interpreting it).

## Report Structure
The provided `.pbix` contains **one report page** with **nine visual elements**. Its report references the `Sales`, `Geo`, `Products`, and `People` tables.

## How to Open
1. Install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
2. Download `Chocolates Sales Dashboard - Complete Project.pbix` from this repository.
3. Open the file in Power BI Desktop.
4. Explore the visuals and any available interactions.

## Suggested Analysis Questions
- Which geographic markets contribute the most sales?
- How do sales vary month to month?
- Which product categories generate the highest sales?
- How does salesperson performance compare by category?
- How do sales totals relate to boxes sold and shipment counts?
